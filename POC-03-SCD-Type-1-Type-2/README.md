# POC 3: SCD Type 1 and Type 2 using Databricks

## Objective
Implement Slowly Changing Dimensions (SCD) Type 1 and Type 2 using Databricks SQL, PySpark, and Delta Lake.

## Concepts Covered
- Initial and incremental loads
- Delta Lake MERGE
- Change detection using null-safe comparisons
- SCD Type 1 updates
- SCD Type 2 historical versioning
- Surrogate keys using identity columns
- Deduplication and data validation

## Environment
- Databricks Free Edition
- PySpark
- Databricks SQL
- Delta Lake

## Project Status
Personal hands-on learning POC.
